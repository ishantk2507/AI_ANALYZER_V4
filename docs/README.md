## Document status

These documents are planning and operating artifacts, not proof that every described feature exists. Each item is classified as:
- **Current** — visible in the inspected repository snapshot.
- **Planned** — a proposed change, not implemented.
- **Needs verification** — repository or runtime evidence is insufficient.

Update the relevant document in the same pull request as any material architecture, product, security, or workflow change. Prefer a short decision record over silently changing a long-standing design assumption.
